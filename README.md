# Leo Portfolio

A professional, minimalist, responsive single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. Alternatively, open this folder in VS Code and use Live Server.

## Before publishing
- Verify all biography and project descriptions.
- Add your preferred public contact email if you want one displayed.
- Add or update project links as your work progresses.
- The GitHub links currently point to `https://github.com/t-leo-n`.
- NERA links to `https://t-leo-n.github.io/NERA/`.

No build tools or npm packages are required. Google Fonts are optional; system fallbacks are included.
